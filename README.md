One emoji. One dream vacation. The entry is exactly this:

```
🌅
```

Why the sunrise: a judge reads entries two at a time and picks the single emoji that most makes a stranger want to book the flight. The field is crowded with the obvious beach and plane picks (🏖️ 🏝️ ✈️ 🌴) — a plane says "travel", but a sunrise says "the place you dream of waking up in". It scored highest against the rubric: instant wanderlust (9/10), distinctiveness from the beach/plane crowd (7/10), universality — a sunrise reads in every culture (10/10) — and emotional pull: warmth, hope, new beginnings (9/10). Total 35/40, ahead of 🏔️ Mountain (32), 🧭 Compass (30), 🏝️ Desert Island (28), and ✈️ Airplane (24).

## Run it

```sh
node main.ts
```

This writes the entry to `/output/entry.txt` (exactly one emoji, no trailing newline).
